# 걱정 저울

이 걱정은 정말 필요할까? 구더기 무서워 장 못 담글까. 에니어그램 6번(충성가) 이야기를 바탕으로, 걱정을 **가능성 × 크기**로 저울에 달아 "대비할 걱정 / 함께 나눌 걱정 / 지켜볼 걱정 / 기인지우"로 나누고, 시간이 지난 뒤 실제로 일어났는지 기록해 보는 앱입니다. 1분 용기 계기판과, 홀로 남겨지는 두려움을 다독이는 기댈 곳 지도도 담았습니다. 「에니어그램 6번 충성가」 [Psyche 08] 부록이며, 파일 하나(`index.html`)로 인터넷 없이 동작합니다.

> **바로 하기: https://woojuntaek-lgtm.github.io/worry-scale/**

## 특징
- ⚖️ 걱정 달기: 걱정 한 줄 + 일어날 가능성(%) + 크기(1~5) + 할 수 있는 것 여부 → 저울 애니메이션과 분류, 대비 행동 기록, 기인지우는 바람에 날려 보내기
- 📦 걱정 상자: "실제로 일어났나요?" 사후 기록 → 걱정한 것 중 실제로 일어난 비율
- 🦌 용기 계기판: 12문장 1~5점 → 신중·걱정·용기와 상태(든든한 사슴 / 기우 주의보 / 돌다리만 두들기는 중 / 스며드는 물 / 잠시 지친 마음), 맞춤 처방
- 🏡 기댈 곳 지도: 가장 가까운 / 믿을 만한 / 기관·제도 세 겹의 원에 이름 적기
- 🦌 6번 한눈에: 사고형 안의 자리, 동양 수리(水·1+5), 사슴·브라운, 두려움, 순응형, 용기와 겁, 날개, 스트레스·성장 방향

성찰을 돕는 참고용이며 심리검사나 전문 상담을 대신하지 않습니다. 입력 내용은 기기 밖으로 나가지 않습니다.
